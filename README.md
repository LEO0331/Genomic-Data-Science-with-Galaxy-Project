# Galaxy Genomic Variant Workflow Case Study (Next.js Portfolio App)

This repository is now a deployable portfolio website that presents a genomic variant-calling project as a modern web case study.

## Website Purpose

This app is an **interactive web presentation and VCF exploration tool based on a Galaxy genomic variant-calling workflow**.

It demonstrates how sequencing analysis outputs can be communicated through a professional web interface that includes:
- Workflow storytelling
- Tool-chain transparency
- Downloadable project artifacts
- Interactive VCF inspection in the browser

## Scientific Context

The underlying project analyzes DNA polymorphic sites from father-mother-child paired-end resequencing data.

Core heavy-compute workflow (performed in Galaxy) includes:
- FastQC quality control
- Bowtie2 mapping
- BAM processing (read groups, merge, filtering, duplicate marking, cleaning)
- FreeBayes variant calling
- VCF filtering
- ANNOVAR annotation
- Variant counting by gene

## What The App Does

- Presents a polished homepage suitable for engineering and bioinformatics portfolios
- Visualizes the Galaxy pipeline on `/workflow`
- Provides a browser-based VCF explorer on `/variants` with:
  - sample VCF loading from `/public`
  - local `.vcf` upload
  - search and filter by chromosome/type
  - summary metrics
  - filtered CSV export
- Offers downloadable artifacts on `/downloads`

## What The App Does NOT Do

- Does **not** run raw FASTQ/BAM processing in the browser
- Does **not** replace Galaxy or provide online high-throughput genomic computation
- Does **not** execute alignment, variant calling, or annotation pipelines server-side

This app is for **presentation, exploration, and interpretation of results already generated by Galaxy**.

## Tech Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Client-side VCF parsing
- Vercel-ready deployment

## Run Locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Optional validation:

```bash
npm run typecheck
npm run build
```

## Deploy to Vercel

1. Push this repository to GitHub.
2. Import the repository in Vercel.
3. Use default settings:
   - Framework Preset: `Next.js`
   - Build Command: `npm run build`
   - Output: `.next`
4. Deploy.

## Included Public Artifacts

The original project artifacts are copied into web-safe names under `/public`:
- `/public/galaxy-workflow.ga`
- `/public/galaxy-project.pdf`
- `/public/filtered-variants.vcf`

Original research files remain in place and are not deleted.
